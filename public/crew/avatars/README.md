# Rendezvous crew avatar starter pack

This directory contains the first six 2D crew avatar assets for the crew lounge concept.

- Transparent RGBA PNGs, 1024×1536
- Hair palette: black, brown, yellow
- Hair variants: short, perm, long, bob
- The assets are visual starter assets; avatar composition should keep identity, trust rank, or participation scoring separate from appearance.

The TypeScript metadata lives in `lib/crew-avatars.ts`. Keep the public avatar path stable so the crew lounge and future avatar editor can use the same definitions.
