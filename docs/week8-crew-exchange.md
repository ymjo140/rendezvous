# 8주차 — 크루 간 공개 리스트 교류

## 이번 주 목표

7주차에서 만든 검증 방문 아카이브가 “우리 크루의 실제 기록”을 보여줬다면, 8주차는 다른 크루와 기록이 오가는 경로를 만든다. 새 게임 이동·가상 재화·허위 활동 점수는 추가하지 않고, 이미 서버가 보관 중인 공개 리스트 복사 원장을 화면에 연결한다.

## 구현

- \`ListCopyEvent\`를 크루 교류 원장으로 사용
- 다른 공개 크루의 리스트를 우리 크루에 담아온 기록 표시
- 우리 공개 리스트가 다른 공개 크루로 이어진 기록 표시
- 크루명·아이콘·리스트명·추가 장소 수·시점만 노출
- 복사한 사용자 ID와 비공개 크루 활동은 노출하지 않음
- 우리 크루 화면에 데이터 0건 상태와 “다른 크루 리스트 둘러보기” CTA 추가
- 기존 \`mission?action=borrow\` 흐름과 연결
- 새 Supabase 테이블·마이그레이션 없음

## 데이터 원칙

- 실제 \`creditable = true\`인 크로스 크루 리스트 복사만 교류로 인정
- 현재 공개 상태인 원본 리스트와 크루만 공개 교류에 포함
- 리스트가 비공개 전환되거나 크루가 비공개가 되면 외부 교류 화면에서 숨김
- 교류 횟수·장소 수는 원장에 저장된 \`added_count\`를 사용하며, 0건이면 숫자를 만들지 않음
- 운영 데이터가 부족한 초기에는 \`collecting\` 상태를 표시

## 수용 기준

- 다른 크루의 공개 리스트를 담으면 “우리가 담아온 기록”에 나타남
- 우리 공개 리스트를 다른 공개 크루가 담으면 “우리 리스트에서 이어진 기록”에 나타남
- 비공개 크루 또는 \`creditable = false\` 이벤트는 나타나지 않음
- 사용자 ID는 API·UI에 포함하지 않음
- 교류가 없으면 빈 상태와 다음 행동 CTA만 표시
- 기존 Backend/Frontend/PostgreSQL CI와 공개 범위 테스트를 통과해야 함
