# 랑데부 리디자인 — 모임·단체 중심 홈 (redesign/group-home)

> 브랜치: `redesign/group-home` · 프리뷰: Vercel 브랜치 프리뷰 URL
> 프로토타입 라우트: `/home-next` (기존 탭 홈 `app/page.tsx`는 그대로 유지)

## 1. 전략 전환 요지

**접은 것:** "모임 장소를 대신 정해주는 결정 도구"
→ 저빈도(설문상 주 1–2회 약속 71%), 카톡과 정면 경쟁, 결정되면 휘발.

**세우는 것:** "믿을 만한 집단(모임·단체)이 **실제로 다녀온** 맛집 리스트를 신뢰 기반으로 발견·소비하는 플랫폼."

한 줄 가치:
> **"광고 아닌, 내가 신뢰하는 집단이 실제로 다녀온 맛집 리스트."**

## 2. 우리만의 무기 3개 (차별점의 뿌리)

1. **실제 방문·재방문 데이터** — 블로그·인스타 리스트엔 없는 것. "정말 다시 갔는지"가 최고의 신뢰 신호.
2. **취향 벡터 매칭** — 아무 리스트가 아니라 "나와 입맛 N% 겹치는 무리"를 앞세움.
3. **집단 정체성 = 큐레이션 보증** — 익명 블로거가 아니라 "성수 와인 모임" + 방문 인증 배지(화해式).

## 3. 홈 구성 (확정)

위 → 아래:

1. **검색바** — 지역 × 맥락 ("성수 데이트, 강남 회식")
2. **취향 매칭 히어로** — 온보딩 취향으로 신규 유저도 바로 채움 → 발견 훅 *(결정 B: 신규엔 이걸 먼저)*
3. **내 모임** — 없으면 "우리 모임 만들기" 강조 CTA로 **모임 생성 유도** *(결정 B 핵심)*
4. **맥락별 랙** — "요즘 뜨는 회식 / 데이트하기 좋은 / 혼밥 성지" (가로 스크롤)
5. **실시간 급상승** — 지금 사람들이 담는 리스트 (기존 소셜 랭킹 재활용)

원칙: 위에서부터 **우리(집단) → 나와 겹치는 우리 → 맥락** 순. 개인화는 흔하니, "누가 검증했나(집단)"를 절대 숨기지 않는다.

## 4. 확정된 결정

- **A. 지도** = 없애지 않고 **탭 중 하나로 유지.** 홈은 발견 피드로.
- **B. 신규 유저 흐름** = 온보딩 취향 → 취향 매칭/발견 먼저 노출 → 모임 가입/생성 유도 (**모임 생성이 목표**).
- **C. 맥락 태그 체계** = 보류 (데이트/회식/혼밥/기념일/뒤풀이/비건… 개수·분류 추후 확정).

## 5. 격리 방식

- **프론트** = 이 브랜치 + 새 라우트 `/home-next` 로 격리. Vercel 브랜치 프리뷰로 확인. `main` 프로덕션 무손상.
- **백엔드** = additive(기존 API에 필드 추가)만 → `main` 직행 안전. 구버전 화면은 새 필드 무시.

## 6. 이미 있는 부품 (재활용)

큐레이터/모임 리스트, 담기, 담은 사람 수(`list_saves`), 취향 벡터, 방문·재방문 데이터, 실시간 급상승 랭킹.
