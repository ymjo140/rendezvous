# 6주차 — 크루 라운지와 랭킹 연결

## 이번 주 완료 범위

- PR #9에서 만든 2D 크루 아바타와 라운지를 크루 상세 화면에 실제 연결
- 라운지의 방문 기록·리뷰 보관함·추천 장소 타일이 아래 기록 탭으로 이동
- 크루 랭킹 타일이 내 크루 화면의 공개 크루 랭킹으로 이동
- 기존 `GET /api/group-ranking`을 활용해 공개 크루 랭킹을 표시
- 랭킹 데이터가 적을 때 숫자를 억지로 만들지 않고 관찰 대기 상태를 표시
- 새 Supabase 테이블·권한·마이그레이션 없음

## 데이터가 적은 초기 운영 원칙

현재 랭킹은 공개 크루의 팔로워·공개 리스트 좋아요·리스트 수를 기반으로 하는 기존 활동 신호다. 방문 인증 데이터가 충분히 쌓이기 전까지는 이를 실제 방문 신뢰도와 동일시하지 않는다. 방문 인증·재방문을 랭킹 점수에 포함하는 변경은 표본이 쌓인 뒤 별도 기준 확정 후 진행한다.

## 검증

- 라운지 미렌더링 누락을 수정해 크루 상세 화면에서 확인 가능
- 랭킹은 공개 크루가 0개여도 오류 대신 빈 상태를 표시
- API 실패 시 기존 `CrewLoadError` 재시도 경로를 사용
- 기존 데이터 모델과 Supabase 정책은 변경하지 않음
